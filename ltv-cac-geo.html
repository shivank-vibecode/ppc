Methodology (analyst notes)

Restricted to depositors with a positive lifetime deposit from the PPC user-level extract. Per user, LTV value = the higher of lifetime_pnl and revenue_first_180_days. D180 LTV = winsorized mean (p1–p99) of that value among depositors aged ≥180 days. CAC bands are D180 LTV ÷ 2 / 3 / 4. Whales = within each country, depositors above the 95th percentile of positive LTV. Campaign-name correlation uses the same whale flag on D180-mature depositors (Europe excluded). Geo-adjusted lift = observed whales / expected whales from each user's country whale rate. Region tiers parsed from the first campaign token: africa_tier1–5, asia_tier1–2, jm, latam, middle_east, cis.
